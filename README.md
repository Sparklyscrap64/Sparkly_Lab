# ✦ Sparkly Lab

**A small digital playground for learning, experimenting, and creating.**

Sparkly Lab is a personal web development project where I explore ideas, experiment with code, and build small interactive web applications.

The project focuses on learning the fundamentals of web development through simple experiments using HTML, CSS, and JavaScript.

## ✨ Experiments

### 01. Text Animation

A simple typing animation that displays text character by character.

**Features:**

- Typing animation effect
- Start and reset controls

### 02. Color Generator

A random color generator for discovering new colors.

**Features:**

- Generate random colors
- Display HEX color codes
- Copy HEX codes to the clipboard

### 03. Digital Clock

A digital clock that displays the current time and date.

**Features:**

- Real-time clock
- 12-hour and 24-hour formats
- Show and hide date

More experiments will be added as the project grows.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

No frameworks or external libraries are required for the current experiments.

## 🎨 Design Philosophy

Sparkly Lab uses a minimalist monochrome design with a focus on simplicity, readability, and functionality.

Each experiment has its own CSS and JavaScript files to keep the code organized, maintainable, and easy to develop independently.

## 🚀 Getting Started

You can run Sparkly Lab locally without installing additional dependencies.

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd sparkly-lab
   ```

3. Open `index.html` in your browser.

4. Select an experiment from the homepage and start exploring!
